# Countie 倉庫盤點小幫手

線上使用：https://farchi09.github.io/countie/

給 65 歲以上長輩用的手機盤點網頁。用下拉選單選商品，填箱、盒、袋的數量，完成後產生一張摘要圖，直接傳 LINE。

取代原本「用手機打開 Excel、放大找格子填數字」的做法，避免看錯列、填錯欄。

## 功能

- **選商品**：44 項商品內建在工具裡，可以打字搜尋（例如打「薑」只剩薑一壺）。已盤點過的商品會標示「已盤點」。
- **填數量**：選好商品後直接出現該商品的輸入格（多數是箱、盒；有袋裝的是箱、盒、袋），可用 ＋／− 按鈕或直接打數字。
- **增加／減少**：同一商品再次輸入時可選增加或減少。例如盤到 10 盒，有人買走 3 盒，就輸入「減少 3 盒」，結果為 7 盒。不能減成負數。
- **分筆合併**：同一商品可以分多筆輸入（例如先填盒數、後填箱數），摘要圖會合併成一列。
- **修正**：每筆輸入都列在「已盤點」區，可以單筆刪除，合計自動重算。
- **摘要圖**：按「完成，產生摘要圖」，產生直式 PNG，內容包括：
  - 有庫存的商品與數量
  - 庫存為 0 的商品（醒目底色）
  - 這次沒有盤點到的商品
- **暫存**：資料存在手機瀏覽器，中途關掉再打開仍在。「清空」需連按兩次才會刪除。

## 盤點記法

每項商品記「完整箱數＋散裝數量」，不換算總量。貨架上有 2 整箱和 5 盒散裝，就記成 2 箱 5 盒。只接受整數。

## 部署

這是靜態網頁，任何靜態主機都能放。

**Netlify（最簡單）**
1. 登入 Netlify，進入 Sites。
2. 把整個資料夾（或 zip 解壓後的資料夾）拖進 Deploy 區。
3. 取得網址，傳給長輩，請他們在手機上「加入主畫面」。

**GitHub Pages**
1. 推上 GitHub repo。
2. Settings → Pages → Source 選 `main` branch、根目錄。
3. 網址為 `https://<帳號>.github.io/<repo 名稱>/`。

放在自己的網站後，「分享」按鈕可以直接叫出 LINE；若手機不支援，長按摘要圖即可儲存或分享。

## 維護商品清單

商品清單寫在 `index.html` 裡的 `const P=[ ... ]`，每一項格式為：

```js
["商品名稱","單位"]
```

單位是一串字，每個字一格，例如 `"箱盒"`、`"箱盒袋"`、`"箱罐"`、`"箱袋"`。

- **新增商品**：在想要的位置加一行。
- **下架商品**：刪掉那一行。
- 清單順序就是下拉選單和摘要圖的順序。

> 注意：商品以「在清單中的位置」辨識。新增、刪除或調整順序後，請把 `const KEY="mei-inventory-v2"` 的版本號加一（例如改成 `v3`），讓手機上的舊暫存資料自動作廢，避免數字對到錯的商品。請在沒有人正在盤點時更新。

## 資料與隱私

- 沒有後端、沒有資料庫、不需要登入。
- 盤點資料只存在使用者自己的手機瀏覽器（localStorage），不會上傳到任何地方。
- 不讀取、也不寫入原本的 Excel 盤點檔。

## 不在第一版範圍

- 讀取或寫回 Excel
- 歷次盤點紀錄、與上次比較
- 箱與盒的換算
- 多人同時盤點
- 到期日記錄
